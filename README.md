# WanderLust - Full Stack Airbnb Clone

A full-stack web application like Airbnb where users can explore, create, and review property listings with live map integration.

### 🚀 Live Demo
Coming Soon...

### ✨ Features
- Authentication - Signup, Login, Logout with Passport.js
- CRUD for Listings - Create, Edit, Delete your stays
- Image Upload using Cloudinary
- Interactive Maps with MapLibre
- Reviews & Rating System
- Fully Responsive Design

### 🛠️ Tech Stack
- Frontend: EJS, Bootstrap, JavaScript
- Backend: Node.js, Express.js
- Database: MongoDB Atlas
- Services: Cloudinary, MapLibre, Passport Auth

### ⚙️ How to Run Locally
1. Clone the repo: `git clone https://github.com/rohitsharma902495/wanderlust.git`
2. Install packages: `npm install`
3. Create .env file and add your keys
4. Run: `npm start`
